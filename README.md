# OPITECH

OPITECH is a universal personalized technology recommendation website.

## Current version
This starter includes:
- Orange / yellow / white UI
- Responsive landing page
- Device category selector
- Recommendation preference form
- Frontend profile-generation demo

## Run
Open `index.html` in a browser.

## Next backend
Connect the form in `script.js` to your backend API. The backend should:
1. Parse the user's requirements.
2. Query your product database / product APIs.
3. Score products against the user's priorities.
4. Return matched products and explain the trade-offs.

Never put private API keys in frontend JavaScript. Keep them on the backend.
